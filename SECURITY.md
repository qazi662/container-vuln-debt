# Security

This repository measures publicly known vulnerabilities (CVEs) in public container images. It does not contain exploits, and it does not test whether any vulnerability is exploitable.

If you find a security problem in this project's own code or workflows, please open a private security advisory on GitHub (Security tab, "Report a vulnerability") rather than a public issue.

Vulnerabilities in the scanned images themselves should be reported to the image maintainers, for example through https://github.com/docker-library/official-images.
